# Timeline example

This is the shape the matching snippet inserts. It names itself, describes
itself, and sets no theme, so Check Markdown, Alt+F9, reports nothing.

```mermaid
timeline
    title How it happened
    accTitle: How it happened
    accDescr: Three periods in order, each with what happened in it.
    2024 : It began
    2025 : It grew
    2026 : It finished
```
