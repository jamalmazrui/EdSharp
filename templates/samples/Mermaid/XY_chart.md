# XY chart example

This is the shape the matching snippet inserts. It names itself, describes
itself, and sets no theme, so Check Markdown, Alt+F9, reports nothing.

```mermaid
xychart-beta
    title "Sales by quarter"
    accTitle: Sales by quarter
    accDescr: A line rising across four quarters, from the lowest value in the first to the highest in the fourth.
    x-axis [Q1, Q2, Q3, Q4]
    y-axis "Sales" 0 --> 100
    line [20, 45, 60, 85]
```
