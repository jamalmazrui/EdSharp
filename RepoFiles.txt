; RepoFiles.txt -- what the EdSharp repository carries.
;
; One path per line. A trailing slash names a folder wholesale. homerTidy
; writes .gitignore from this as a WHITELIST -- everything ignored, then
; exactly these allowed -- and gitPush rewrites it before every push, so
; "git add -A" means "add what the project has named", never "everything in
; the folder".
;
; Nothing binary is named here. The program, its libraries and the installer
; are built into exec\ and named in LocalFiles.txt.

; THE ONE BINARY. Tektosyne.dll cannot be fetched -- no NuGet package, no
; download -- so the repository has to carry it. The rule against binaries
; here exists to keep fetched things out of git; a thing that cannot be
; fetched is the exception the rule allows. homerTidy carried it off once.
Tektosyne.dll

; THE SECOND BINARY, for a different reason. nvdaControllerClient.dll is
; published by NV Access beside each NVDA release, at an address that
; carries the release number -- so the address the build fetched from dies
; every few months, and on 25 September it returned 404 for the third
; build in a row. The library itself has not changed since NVDA 2024.1,
; it is about 260 KB, and EdSharp's speech to NVDA users depends on it.
; Carrying it is safer than a fetch that fails on a fresh clone. The
; build still tries to refresh it, and says so quietly when it cannot.
nvdaControllerClient.dll
