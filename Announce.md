# What's New in EdSharp

### A text and code editor rebuilt for the way screen reader users actually work

- [EdSharp project page on GitHub](https://github.com/JamalMazrui/EdSharp)
- [EdSharp installer for Windows](https://github.com/JamalMazrui/EdSharp/releases/latest/download/EdSharp_setup.exe)

EdSharp is free and open source, for Windows, and it aims at one thing: to be
the most productive text and code editor available to a screen reader user
today. This is a reborn EdSharp, more powerful than any version before it. The
latest AI has been used throughout -- to check the old code, update and
modernize it, and build features that were not practical to write before.

Twelve tutorials, opened with the Tutorials command, start you off by the kind
of work you do rather than with a tour of the program. Here is what each one
finds.

## If you write

The Spell Check command no longer needs Microsoft Word. It walks the document
one misspelling at a time, saying and spelling each word and offering
suggestions you can arrow through or type over. The Thesaurus command gives
synonyms grouped by meaning, each with a short definition.

Open a Word document, a PDF, a slide deck or a spreadsheet with the Open Other
Format command and read it as text. A PDF keeps its headings, lists and
tables, so you can move through it by block. Write any of them back out with
the Export Format command. Plain text, Markdown and HTML work as both input
and output throughout.

## If you research

The Web Download command fetches a page or file, and Open Other Format turns
it into readable text. The Append from Clipboard command makes the current
window a collector, so everything you copy stacks into one document in order
-- three sources, one set of notes. Chat with AI then summarizes what you
gathered.

## If you translate

The Translate Language command translates the selection or the whole document
between eighteen languages and opens the result in a new window. It runs on
your own machine, so there is no account, no limit, and nothing sent anywhere.

## If you program

The Pick Compiler command chooses your language, and that one choice brings
the command to run, the way errors are read, the indentation the language
uses, and its interactive shell. Python, Node.js, C#, PowerShell, JAWS script
and JScript .NET are ready configured. The Compile command, Control+F5, then
runs the file and lands the cursor on the earliest error, with your own path
abbreviated out of the speech.

The Go to Environment command opens a console where the editor window and its
text box are already in scope, so a line tried at the prompt is a line that
works in a snippet. Chat with AI, F12, sends questions about a source file to
a model trained on code.

## If you work in bulk

The File Find command lists matching file paths in a window you can edit, and
the Transform Files command applies a set of search and replace tasks to every
file in that list. Regular expressions run through find, replace, and two
commands that pull matching text into a new document.

## For everyone

EdSharp now leaves window titles and focus changes to your screen reader,
which announces them anyway, and speaks only what it alone knows. The Key
Describer command, Control+F1, describes every command in the program; press a
key and hear what it does without doing it, and nothing answers "no
description available" any more.

Documentation comes with it and is meant to be read: a user guide covering
every command and setting, the twelve tutorials by role, a hotkey reference
listing every command by name and by key, a questions and answers file, a
history of what changed and why, and a developer guide. Each is a web page the
Help menu opens, and a Markdown file you can read in EdSharp itself.

## Getting the pieces

Everything optional is a checkbox on the installer's last page, each saying
what it will do and how large it is, and each fetched and installed
automatically: Python and the document tools, Git, Node.js, and the AI models
for chat, translation and code. Nothing is a manual download.

The AI features trade installation size for local power and privacy. Several
gigabytes of models buy translation, summarizing and coding help that ask no
account, impose no limit, and never send a document anywhere.
