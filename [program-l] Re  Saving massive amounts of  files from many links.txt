I have develop two .NET-based programs that include a feature for downloading all files linked to a web page:

EdSharp, a text and code editor
www.EmpowermentZone.com/edsetup.exe

and
FileDir, a file and directory manager
www.EmpowermentZone.com/dirsetup.exe

In either program, the Web Download command, Alt+Shift+W, prompts for the address of the web page to analyze.  Next, a list of possible extensions is presented so one can choose, say, only .doc and .pdf files.  Then a multiple selection listbox allows one to further filter if desired (or select all items with Control+A).

For software with a more comprehensive set of download features, I recommend the following free program:

HTTrack Website Copier
www.httrack.com/
