Great to see EdSharp getting some love. Here are a couple of thoughts.

 

Unfortunately, the new version does not work on my machine with an ARM processor. I hope this can be allowed for.

I'd like to see the append from clipboard (alt+7) command be checked. I know there are lots of other ways to get a similar result, but I've grown fond of this one. In Windows 10 it never failed. In Windows 11 it sometimes fails, and I never know when it will fail, thereby crashing EdSharp, or work.

 

 I'd love a macro recorder, and/or some work on the alt+= command. It tended not to work when I tried it.

 

I'd love the ability to easily stop EdSharp from acting on .brl and .brf files. I just want to see the code, not have it back-translate.

 

I have long appreciated EdSharp and hope you find some of these ideas acceptable to include in the new version, if I can run it.

 

Dean

This is to announce release of a new, 5.0 beta version of EdSharp, a text and code editor optimized for screen reader users. It is the first public release in over a decade, motivated partly by requests from users and by the development assistance offered by AI. This is the first 64-bit version of EdSharp, compiled on the latest version of the .NET Framework that is built into all modern Windows computers.

In this update, I have tried to fix bugs and solidify features. A tutorial and user guide are included, as well as various help mechanisms. I welcome feedback to improve the project, requesting such communication to be via direct message if possible (email, Facebook, LinkedIn, or text). Replies to this announcement are also welcome as long as a lengthy message thread does not result.
