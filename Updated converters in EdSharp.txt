Based on interest in the txt2tags utility from
http://txt2tags.org

I have added it to the EdSharp distribution, along with EdSharp.ini configuration entries for converting between the txt2tags format and many others, including HTML, LaTeX, DocBook, and MediaWiki.  Due to the way that EdSharp parses such conversion entries, the extension to use for a file in text2tags format is .tt rather than .t2t (in the ini file, the digit 2 separates source and target extensions).

A sample file in text2tags format, sample.tt, has been placed in the default snippet folder (Alt+V pastes a snippet).  Documentation for the txt2tags format has also been added to the collection of text tutorials at
http://EmpowermentZone.com/html_doc.zip

That archive also includes documentation on the Markdown format, which has a similar purpose as a lightweight, readable format that can convert to various target formats.  The Pandoc utility from
http://johnmacfarlane.net/pandoc/

is included with EdSharp for such Markdown conversions, which have Rich Text Format (.rtf) as another option.  A .pdf target is also supported if one installs MiKTeX from
http://miktex.org/

If you already have EdSharp installed, you can update via the Elevate command, F11.  Otherwise, you can download from
http://EmpowermentZone.com/edsetup.exe
