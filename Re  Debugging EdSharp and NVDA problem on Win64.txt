OK, I have now posted new versions of EdSharp
http://EmpowermentZone.com/edsetup.exe

and FileDir (a file and directory manager)
http://EmpowermentZone.com/dirsetup.exe

The executables EdSharp.exe and FileDir.exe run as 32-bit processes, including on 64-bit Windows, which maximizes compatibility with existing screen readers (JAWS, NVDA, System Access, and Window-Eyes).  If a user would rather run a version in 64-bit mode on 64-bit Windows, the EdSharp64.exe or FileDir64.exe version may be used instead.  For example, edit the EdSharp or FileDir shortcut on the desktop so that it points to the executable with the 64 suffix.

Jamal
