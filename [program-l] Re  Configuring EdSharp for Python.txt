Hi Brandon,
EdSharp uses a RichEdit control for the editing area, similar to WordPad.  Functionality is constrained by the behavior of that control.  If you find a different JAWS reading behavior in WordPad compared to EdSharp, I would be interested to know.

Regarding the tab issue, I am having trouble replicating the problem.  I do not have JAWS 11 installed currently, but am running JAWS 12, which does say "tab" when reading the current character in EdSharp.  The Tab key will only insert a tab character, however, if that character is set as the indentation character sequence.  I forget what the default is, but you can set this by pressing Alt+Shift+C for the Configuration Options dialog, Alt+I to jump to the IndentUnit field, and then entering "\t" without the quotes.

I agree that the change in indentation level would be better said before rather than after the current line is read when indent mode is on.  Unfortunately, I have not found a way to reliably do that. The code relies on an event of the control that indicates a change of caret position.  When EdSharp notices a change in indentation during the event processing code, it announces the change.  By that time, however, JAWS has already read the line when down arrowing.  I did not find a way around this timing problem.  If anyone else figures out a solution, let me know.

The sound scheme archive needs to be put in the appropriate subdirectory under Settings/Enu.  Then the following tip may help explain next steps to take, excerpted from the history of changes file (available from the Help menu):

"Another approach to hearing indentation levels is a JAWS sound scheme contributed by Jim Homme.  You can install it by pressing JAWSKey+F2 and choosing Settings Packager.  In that program, press Control+O and enter Sounds4Stuff.zip.  Then press Alt+I to import the settings.  "

Control+\ just takes you to a command prompt in the current directory of the EdSharp process.  More automation would be possible by invoking a custom snippet.

Thanks for your interest.

Jamal
