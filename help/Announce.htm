A text and code editor rebuilt for the way screen reader users actually work

What's New in EdSharp

EdSharp is free and open source, for Windows, and it aims at one thing: to be the most productive text and code editor available to a screen reader user today. This is a reborn EdSharp, more powerful than any version before it. The latest AI has been used throughout -- to check the old code, update and modernize it, and build features that were not practical to write before.

Twelve tutorials, opened with the Tutorials command, start you off by the kind of work you do rather than with a tour of the program. Here is what each one finds.

If you write

The Spell Check command no longer needs Microsoft Word. It walks the document one misspelling at a time, saying and spelling each word and offering suggestions you can arrow through or type over. The Thesaurus command gives synonyms grouped by meaning, each with a short definition.

Open a Word document, a PDF, a slide deck or a spreadsheet with the Open Other Format command and read it as text. A PDF keeps its headings, lists and tables, so you can move through it by block. Write any of them back out with the Export Format command. Plain text, Markdown and HTML work as both input and output throughout.

If you research

The Web Download command fetches a page or file, and Open Other Format turns it into readable text. The Append from Clipboard command makes the current window a collector, so everything you copy stacks into one document in order -- three sources, one set of notes. Chat with AI then summarizes what you gathered.

If you translate

The Translate Language command translates the selection or the whole document between eighteen languages and opens the result in a new window. It runs on your own machine, so there is no account, no limit, and nothing sent anywhere.

If you program

The Pick Compiler command chooses your language. That one choice brings the command to run, the way errors are read, the indentation the language uses, and its interactive shell. Python, Node.js, C#, PowerShell, JAWS script and JScript .NET are set up and ready. The Compile command, Control+F5, then runs the file and puts the cursor on the first error. Your own folder path is left out of what is spoken.

The Go to Environment command opens a console where the editor window and its text box are already at hand, so a line that works at the prompt also works in a snippet. Chat with AI, F12, sends questions about a source file to a model trained on code.

If you work in bulk

The File Find command lists matching file paths in a window you can edit, and the Transform Files command applies a set of search and replace tasks to every file in that list. Regular expressions run through find, replace, and two commands that pull matching text into a new document.

For everyone

EdSharp now leaves window titles and focus changes to your screen reader, which announces them anyway. It speaks only what it alone knows. The Key Describer command, Control+F1, describes every command in the program: press a key to hear what it does, without doing it. No key answers "no description available" any more.

The documentation comes with EdSharp and is meant to be read. There is a user guide to every command and setting, twelve tutorials by role, a hotkey reference that lists every command by name and by key, questions and answers, a history of what changed and why, and a developer guide. The Help menu opens each one as a web page, and each is also a Markdown file you can read in EdSharp itself.

Getting the pieces

Everything optional is a checkbox on the installer's last page. Each one says what it will do and how large it is, and each is fetched and installed for you: Python and the document tools, Git, Node.js, and the AI models for chat, translation and code. Nothing needs a manual download.

The AI features trade disk space for local power and privacy. Several gigabytes of models bring translation, summaries and coding help that need no account, have no limit, and never send a document anywhere.
