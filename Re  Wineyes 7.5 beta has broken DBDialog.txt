One little EdSharp issue which isn’t really a problem, but just in case you are not aware of it: you might know that GW Micro have changed their set file naming convention. Now, when one uses Window-Eyes 7.5 beta 1, EdSharp complains about not finding the set files when it loads. It still loads ok, but it just gives the error messages. Your problem is now that some people are not using the new beta and for them it works fine while it generates the error message for beta users. As I say, not a problem, just something you should know. At some stage you might have to make the call as to which naming convention you are going to use. I think that change could have all kinds of side-effects; not so sure that was a wise move of theirs at this stage.
