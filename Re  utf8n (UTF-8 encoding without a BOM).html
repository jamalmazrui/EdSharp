I recently discovered EdSharp support for UTF-8 that I apparently forgot to document.  In the EdSharp dialog for Configuration Options, Alt+Shift+C, you can use the "utf8n" string to indicate utf-8 encoding without an initial byte order mark (BOM).  I think the string is not case sensitive, and it works whether one puts a dash after "utf8" or not.


If anyone would like to try this, I welcome feedback.
