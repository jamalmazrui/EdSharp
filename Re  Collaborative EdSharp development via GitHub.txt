Hello Jamal,
We discussed getting the Github working, getting code seperated out, figuring out how to configure screen readers to work best with EdSharp and the advantages Notepad++ has over EdSharp.
Here are the commands to connect to the github repository:
First cd into a dir where you can create a new folder.
git clone https://github.com/EmpowermentZone/EdSharp.git EdSharp
*note that the EdSharp at the end of the above command will be the name of the new folder. By default it will be EdSharp, so you don't even need to put it, but if you wanted to change the name of the dir where the repository will be downloaded to, you can do so.
Now make all the changes you want in the new folder. Once you are done, type:
git add *
git commit -m "Put a comment for what you did"
If this is the code to the new version type:
git tag -a v3.4 -m "Message about this release"
*note change the version to be whatever. The current version is 3.3.
To push your new changes to github type:
git push
That's all!

git cheetsheet.txt

git cheetsheet

before everything:
git init

add files to watch
git add filename.txt
remove files to watch:
git rm --cached  filename.txt
Without the --cashed will delete the file
rename files that are already added:
git mv old_name new_name

commit everything
git commit -a -m "First commit"
git commit --amend -m "message" #will change the last commit so it does not show up in the log

see what needs to change
git status

see a list of branches
git branch
if you wish to add a branch, add a name after branch like: git branch testing
if you wish to add a branch from another branch or tag do: git branch name tagName
to delete a branch add -d name like: git branch -d testing

change branches
git checkout branchName

merge branches
git merge branchName
While doing this you may see conflix. To see all of these use
git diff
to merge one file do:
while on the branch that needs the update type
git checkout --patch UpdatedBranchName Filename
to add a new file, do in the branch that needs updated:
git checkout UpdatedBranchName Filename

cloning something from somewhere else
git clone url NewDirName

to get all the changes from another repository to your current branch do:
git pull url OtherRepositoryBranch
To get everything from the external repo on their own seperate branches do:
git fetch url OtherRepositoryBranch
This will add all the branches as: url/branchName

to add everything from your current branch to an external repository do:
git push url localbranchName:urlBranchName #you only need 1 name if they are the same
To push tags do:
git push url tagName
Or to push all tags do:
git push url --tags

add and view repositories
To see the short name of the current remote do:
git remote
to see the url do:
git remote -v
To see info on a remote repository do:
git remote show url

define short-hand repository
git remote add name url
This means that anything with url can be used with name instead
to rename do:
git remote rename OldName NewName
This renames both onboard and in the remote repo.
remove a repo
git rm name
removes from both as well

to check the current remote url do:
git config --get remote.origin.url

check the list of the stored copies of pulled and fetch
git branch -r

see and mark version numbers
git tag
-l #shows all the tags
-l 'v0.*' #will show all the versions in the 0 family.
-a versionNumber -m "message" #creates a new tag. the tag can be like v0.1.1. if you take out the -a -m and message, it won't have an anotation, but don't do that.
If you wish to add a tag on a past commit do:
git tag -a version PartOfOrAllOfHash

to see info and the message of a tag do:
git show versionNumber
or
git cat-file tag versionNumber

to revert to a tag do:
git checkout -b newBranchName TagNumber
While in that tag you can do commits and to keep those commits do: git checkout -b new_branch_name
To push tags do:
git push url tagName
Or to push all tags do:
git push url --tags

see configurations
git config -l

to make aliases do:
git config --global alias.aliasCommand FullCommand
git config --global alias.aliasCommand 'Really long command'
git config --global alias.AliasCommand "!command not part of git"
to change aliases go to .gitconfig which is under brandon/.gitconfig.
to add multipal commands with an alias go to the file and type something like:
[alias] test = !git commit -a -m "random" && git status

shows the log
git log
after log you can put:
-p #for seeing the messages I wrote along with the documents that were changed (it will show the text that was changed)
-2 #place it after -p or whatnot to see only the last 2 messages
--stat #--stat just shows my messages and not the files like -p
-p localBranch..url/UrlBranchName
version1..version2 #the log between version1 and version2
--pretty=oneline #use --pretty= before a command, oneline puts everything on one line.
--pretty=format:"%cn, %cr : %s : %h" #shows name, date, message and summery of hash.
#see:
#http://git-scm.com/book/en/v2/Git-Basics-Viewing-the-Commit-History
#for more

Creating a file that ignores other files:
create a file named: .gitignore
see the .gitignore file for examples
