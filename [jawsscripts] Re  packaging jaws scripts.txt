I personally use JSInstall. You can do a lot with it. You have to also 
download the compiler, but it works great. License screens and such. You'll 
have to edit the ISS file after and recompile by right clicking it and 
selecting compile. The extra file it creates is a configNames.ini file which 
you don't want to start creating. In the ISS file it creates after, find the 
configNames.ini reference and change it to dummyFile.ini and it won't create 
the other stuff.
I found this to be the best and easiest method of deploying a truly custom 
script while still hiding the source code by only giving out the JSB, JKM, 
and JCF files.
