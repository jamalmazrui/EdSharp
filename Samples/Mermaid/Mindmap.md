# Mindmap example

This is the shape the matching snippet inserts. It names itself, describes
itself, and sets no theme, so Check Markdown, Alt+F9, reports nothing.

```mermaid
mindmap
    accTitle: Topic map
    accDescr: A central topic with two branches, each holding two smaller ideas.
    root((Topic))
        First branch
            One idea
            Another idea
        Second branch
            A third idea
            A fourth idea
```
